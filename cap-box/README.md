# MFC Cap Box: 3D-сборка и файлы под дизайн

**Дизайн v1** (по референсам): `design/MFC-box-RevJ_design-v1_outside*`, `design/MFC-box-RevJ_design-v1_inside*` (печать внутри крышки, двусторонняя), `design/MFC-insert-RevC_design-v1*`. Файлы `*_outlined.pdf` и `*_PRINT-mirrored.pdf` — для печати (текст в кривых), `.svg` без суффикса — редактируемые (шрифты в `fonts/`: Montserrat + Cormorant Garamond, OFL).

В 3D есть переключатель ревизий: **Rev L** (по умолчанию, для тестовой печати: петля крышки на конце уступа, чистые углы, язычок-замок на основе), **Rev K**, **Rev J** (предыдущая), **Rev I** и **Rev H** (исходный чертёж). Файлы для фабрики: `MFC_factory-files.zip` / `factory/` (Rev L + вкладыш Rev C).

Коробка **Rev H** (без клея, E-гофра 1,5 мм) и вкладыш под кепку **Rev C**, собранные в одну модель.
Вся геометрия взята из векторных линий исходных PDF (`source/`), а не обрисована по картинке.

## Что здесь лежит

| Файл | Для чего |
|---|---|
| `index.html` | 3D-просмотрщик: вращение, сборка по 11 шагам ползунком, открытие крышки, наложение своего дизайна. Открывается в браузере, нужен интернет (three.js и шрифты грузятся с CDN). |
| `print/MFC-box-RevI-step_dieline.pdf` / `.svg` | **Чертёж Rev I** (новый): уступ 60 мм у задней стенки, боковина основы закрывает вкладыш. Габариты коробки как у Rev H. Изменённые панели обведены оранжевым, справа вид сбоку с вкладышем. |
| `print/MFC-box-RevI_design-template.svg` / `.pdf` | Шаблон для дизайна под Rev I. |
| `print/MFC-box-RevH_design-template.svg` / `.pdf` | **Шаблон для дизайна коробки**, 1:1 в мм. Слои: ARTWORK (рисовать здесь), CUT (высечка), CREASE (биговка), SAFE (3 мм), BLEED (+3 мм), подсказки (стрелка «ВЕРХ» показывает, где верх на собранной коробке). |
| `print/MFC-insert-RevC_design-template.svg` / `.pdf` | То же для вкладыша. |
| `design/MFC-box_concept.svg`, `design/MFC-insert_concept.svg` | Черновой концепт с живым текстом (шрифт Inter / Inter Display) для правки в Illustrator, Figma или Inkscape. Тексты-заглушки нужно заменить. |
| `design/*_outlined.svg` / `.pdf` | Тот же концепт с текстом в кривых. Этот вариант показан на 3D-модели. |
| `data/geometry.json` | Панели, линии сгиба и порядок сгибов (используется просмотрщиком). |
| `tools/` | Скрипты: `build.py` пересобирает всё из PDF, `geometry.py` описывает панели, `viewer.src.html` — исходник просмотрщика. |

## Как работать с дизайном

1. Откройте `print/…design-template.svg` в Illustrator, Figma или Inkscape. Технические слои заблокированы.
2. Рисуйте в слое **ARTWORK**. Фон тяните до пунктира BLEED, текст и логотип держите внутри голубой SAFE-зоны.
3. Ориентируйтесь на зелёные стрелки «ВЕРХ»: на развёртке перед крышки, верх крышки и передний борт перевёрнуты, а боковые стенки повёрнуты на 90°.
4. Панели с подписью «ВНУТРИ» (вкладыши стенок и крышки, внутренний борт) видны изнутри, когда крышка открыта. На панелях «скрыто» печать не видна.
5. Проверка: экспортируйте **весь артборд** в PNG или JPG, откройте `index.html` и нажмите «Свой дизайн: коробка». Картинка ляжет на 3D-модель по высечке.
   Размер артборда: коробка 754,1 × 973,6 мм, вкладыш 973,5 × 396,8 мм.
6. Для фабрики сдают PDF с артворком, тексты переводят в кривые. Слои CUT и CREASE обычно отдают отдельным слоем или берут штамп фабрики. Уточните это у типографии.

## Что заметно на модели (проверьте перед штампом)

- **Щель спереди около 8–9 мм.** Перед крышки 161,7 мм плюс передний борт 28,8 мм дают около 190 мм при высоте коробки 199 мм. Между ними виден язычок. Если так задумано (короткий язычок), то всё в порядке; если нет, перед крышки нужно удлинить.
- **Диагональный шов по бокам** (зазор 5,9 мм) заложен в чертеже. Дизайн на боках лучше строить с учётом этой линии.
- **Вкладыш по высоте впритык.** Крыло вкладыша даёт высоту 195,7 мм, внутренняя высота коробки 196 мм, а верхний клапан добавляет ещё толщину картона. На белом образце проверьте, закрывается ли крышка без усилия.
- Модель учитывает толщину картона приближённо (±1,5 мм). Точные допуски подтверждает типография.
